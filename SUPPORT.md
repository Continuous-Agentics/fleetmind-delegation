# Support

Use GitHub Issues for reproducible defects, documentation gaps, and feature proposals. Use the provided templates and include the affected package and version.

For `@continuous-agentics/delegation-core`, include the relevant task/event compatibility context and redact task content. For the OpenClaw plugin, include the OpenClaw version, plugin version or commit, and a redacted configuration excerpt.

Use [SECURITY.md](SECURITY.md) for vulnerabilities and secret exposure; do not report those publicly.

This repository supports delegation contracts and the OpenClaw integration boundary. Fleet provisioning, Terraform, deployment, and fleet operator behavior are owned by [FleetMind](https://github.com/Continuous-Agentics/fleetmind).
