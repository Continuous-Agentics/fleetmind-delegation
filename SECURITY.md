# Security Policy

## Supported versions

Security fixes target the latest public release of `@continuous-agentics/delegation-core`, the current `main` branch, and the OpenClaw plugin source in this repository.

## Reporting a vulnerability

Do not open a public issue for credential exposure, authorization bypasses, unsafe lifecycle transitions, cross-tenant data access, or other exploitable defects.

Report privately to the maintainers through an agreed private channel. Include:

- affected package, version, and commit when known;
- impact and attack path;
- safe reproduction steps;
- logs or screenshots with all secrets and task contents redacted.

Do not include AWS credentials, npm tokens, NATS credentials, account IDs, or unredacted task narratives. Maintainers will acknowledge the report, assess severity, and coordinate a fix before public disclosure.
